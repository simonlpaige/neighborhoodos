The intent

NeighborhoodOS was created by Simon L. Paige in 2026. He has chosen to hand it off so community organizations, starting with KC Digital Drive, can run it without him. Partners are free to use, adapt, and build on everything here: the code, curriculum, playbooks, safety rules, plans, and the NeighborhoodOS name for programs that follow the Safety Doctrine.

What covers what

Material Terms
Source code MIT License (see LICENSE). Anyone may use, copy, modify, and redistribute it, including commercially, keeping the copyright notice.
Docs, wiki, curriculum, session plans Released for anyone to use and adapt. The author intends these to be treated as openly licensed (for example under Creative Commons Attribution 4.0); a formal license file for non-code content is a pending decision.
The name "NeighborhoodOS" and the domain Use for programs that adopt the Safety Doctrine is welcome. Transfer of the domain or any formal trademark arrangement is a separate step to be agreed in writing.

This page states intent and is not legal advice. Organizations that need certainty for funders should ask for a short signed letter from the author, which he has offered to provide.

Practical handoff checklist

  • [ ] Partner forks or is given admin on the GitHub repository
  • [ ] GitHub Pages / domain DNS ownership decided and transferred if agreed
  • [ ] Contact email on the website, README, wiki, and llms.txt updated to the new program owner (currently simon@simonlpaige.com)
  • [ ] Mirrors (Codeberg) either updated or retired
  • [ ] Signed letter of permission, if requested

October 17, 2026 update

KC Digital Drive adoption is confirmed. Simon L. Paige remains site administrator and advisor; repository and domain ownership have not been transferred. Use KCDD’s public contact page until a dedicated program inbox is supplied. Formal non-code licensing and a signed permission letter remain decisions to record explicitly; no license grant is silently changed by the website release.
