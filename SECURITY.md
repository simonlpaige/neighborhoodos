# Security and Privacy

Do not post personal data, household complaint details, credentials or exploit instructions in public issues.

Send technical security or site privacy concerns to site administrator Simon L. Paige at simon@simonlpaige.com. For program operations use [KC Digital Drive's contact channel](https://www.kcdigitaldrive.org/contact/). Include the URL, a short description and the minimum evidence needed, with private details removed.

No response deadline or bug bounty is promised. Review possible resident harm promptly and suspend affected publication where needed.

The public site has no resident accounts and does not upload problem briefs. Public snapshots contain aggregates and allowlisted infrastructure blocks. Experimental backend modules are excluded from the deployment artifact.
