# Start Here for Partners

This page is for an organization (a digital inclusion nonprofit, a library, a neighborhood association, a campus) that wants to run a NeighborhoodOS program. It assumes no technical staff and no help from the original author.

## The short version

1. You do not need the software to start. Start with education.
2. Name two people: a **program lead** and a **data steward**.
3. Run 3 Learn sessions, then 2 Solve clinics, over roughly 90 days.
4. Build one small tool only if the clinics surface a clear, safe need.
5. Plan the physical space and local hardware in parallel, not first.

## A general plan

### Days 1-30: Set up and Learn
- Confirm lead, steward, room, and dates.
- Recruit 12-25 residents per session through trusted channels. Personal invitations outperform flyers; see [Recruitment and Outreach](Recruitment-and-Outreach.md).
- Print the [facilitator kit](https://neighborhoodos.org/kit/) and read the [Facilitator Guide](Facilitator-Guide.md).
- Run **Learn 1** (What AI is and isn't) and **Learn 2** (Scams, privacy, and checking the machine).
- Collect only what you need: first name and how to reach them, with consent. No addresses.

### Days 31-60: Finish Learn, start Solve
- Run **Learn 3** (Public data and your block).
- Run **Solve Clinic 1**. Collect problems on sticky notes; turn the strongest into one-page Problem Briefs.
- Keep a simple, public log of problems raised and next steps. A shared spreadsheet is fine.

### Days 61-90: Solve and decide
- Run **Solve Clinic 2**. Follow up on Clinic 1 problems first. Show what moved.
- Score the top Build candidate against the [Pilot Rubric](../docs/PILOT-RUBRIC.md). Build only if it scores 7/9 or better and passes the Red-Light Test.
- Write a two-page summary using [Evaluation and Metrics](Evaluation-and-Metrics.md). Decide: continue, change, or stop.

### In parallel: space and hardware
- Reserve a room with good power, network, and seating for 25.
- Budget for one modest local AI workstation (see [Budget and Hardware](Budget-and-Hardware.md)). You do not need it for Learn sessions.

## What success looks like at day 90

- 3 Learn sessions and 2 Solve clinics held.
- 10-20 real problems captured; 3-5 moved to a concrete next action.
- One Build candidate scoped, or set aside with a written reason.
- A handful of residents interested in helping facilitate next time.
- Enough evidence to decide what comes next.

## What to avoid

- Starting with the software or the hardware.
- Promising outcomes the program can't deliver (fixing 311, legal help).
- Collecting data "just in case."
- Letting a vendor or funder turn it into a surveillance or "smart city" product.
