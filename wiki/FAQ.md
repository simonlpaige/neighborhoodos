# FAQ

**Do we need to be technical to run this?**
No. The Learn and Solve tracks need a room, a projector, sticky notes, and a good facilitator. Software only enters at Build, and only if a real need shows up.

**Why start with education instead of the tools?**
Because tools nobody trusts don't get used, and people can't trust what they don't understand. The sessions also tell you which tool is actually worth building.

**Is this anti-AI?**
No. It's pro-people. It teaches where AI helps, where it fails, and how to stay in charge of it.

**Does it replace 311 or city services?**
No. It helps residents use them well and hold institutions to their promises.

**Can we use ChatGPT, Claude, Gemini, or other cloud tools?**
For facilitator demos, yes, with no personal information typed in. For tools that residents type into, prefer a local model on hub hardware.

**What data do you keep about participants?**
As little as possible: a first name and a way to reach them, with consent. No addresses, no attendance scoring. The data steward decides and can delete on request.

**Can the city or police get access to the data?**
The Safety Doctrine prohibits integration with or sharing to law enforcement or immigration systems. The data layer is designed to hold public records and aggregates, not information about individuals.

**We want to use it in another city. Can we?**
Yes. The education program works anywhere. The software needs new data connectors for your city. See [Launching a New Neighborhood](Launching-a-New-Neighborhood.md).

**Who owns it?**
See [Handoff and Licensing](Handoff-and-Licensing.md). Short answer: it's open for community use.

**Who do we ask for help?**
Start with this wiki. For code, open a GitHub issue. The original author may be available occasionally but isn't a support line.
