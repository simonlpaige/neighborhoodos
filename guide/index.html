Who fixes what in Kansas City? for residents. Principles and measures of usefulness for hosts. The workshop manuals below give facilitators a complete learning and problem-solving path.

Facilitator manual: Learn AI safely

Help neighbors practice three skills: check an answer, protect private information, and pause when a message creates urgency. Use the free lesson and printable kit. This is a session plan; check confirmed session information before inviting people.

Facilitator manual: Make a problem brief

Help a neighbor leave with a specific problem, the responsible office, evidence they can check, and a next step they choose. Use the brief builder or a sheet of paper. A complaint can identify a real failure; listen before asking someone to turn it into a plan.

Facilitator manual: Build only what helps

Build after a clinic reveals a repeated task that a small tool can improve. A clearer form, a printable checklist, or a better referral may be enough. This manual describes a decision process, not an operating local AI service.

Operating manual: Public-data snapshots

This manual covers the published NeighborhoodOS dashboards. Their sources are official Kansas City datasets, and their outputs are dated, privacy-filtered JSON snapshots. Experimental connectors elsewhere in the repository are not the public-site pipeline.

Glossary

Aggregate: a count or summary across many records (e.g., "42 open streetlight requests in this area") rather than information about one person. Audit log: an append-only record of administrative and safety events. Rows can be added, never edited or deleted. Build: the track where residents and volunteers co-design a small tool. Data steward: the named person responsible for what data is collected, how it's protected, and deleting it on request. Federation: optional exchange of signed, aggregate-only bundles between neighborhood nodes. Hallucination: when an AI model states something false with confidence. Learn: the AI literacy track. Local model: an AI model running on hardware in the hub rather than on a company's servers. Node: one neighborhood's installation of the software, usually one SQLite database file. Ollama: free software for running open AI models locally. Problem Brief: a one-page description of a local problem: what, who has authority, what evidence, and the smallest next move. Provenance: where a piece of information came from; every fact should link back to its source. Red-Light Test: the six questions in the Pilot Rubric that instantly reject a proposal. Safety driver: core/db.js, the code that refuses banned data structures. Solve clinic: a session where residents turn real problems into Problem Briefs. Socrata: the platform behind Kansas City's open data portal. Legistar: the platform many city councils use for agendas, minutes, and votes. Toothbrush test: does anyone use this at least weekly? If not, reconsider it. Trust level: 0-5 scale in the identity system, earned through verification and vouching, used to decide who can vote on what. Wedge: a single, sharp problem a tool focuses on.

What the work is for

NeighborhoodOS helps neighbors understand a problem, find the right source or office, and choose a useful next step together. AI is one tool for drafting and practice. A person decides what matters and what to do.

Program Design

The order matters. Learn builds trust and shared language. Solve surfaces real needs. Build only happens once a need is real.

Recruitment and Outreach

Turnout is the most common way community programs fail. The fix is almost always the same: personal invitations from trusted people, not flyers.

Roles and Staffing

A small program needs few people, but the roles must be clear. One person can hold two roles, except program lead and data steward should be different people so there is a check on data decisions.

Technical Architecture

NeighborhoodOS software is a small, local-first Node.js codebase built on SQLite. It is designed so one neighborhood can run its own node on one machine, and optionally share aggregate results with other neighborhoods.
